⭐ Pattern Generator & Number Analyser

A simple and interactive Python console application that combines two beginner-friendly programs into one:

🔷 Pattern Generator — Generate a star pattern based on the number of rows.
🔢 Number Analyser — Analyse numbers in a given range, identify whether each number is odd or even, and calculate their total sum.
🚪 Exit Option — Easily exit the program whenever you're finished.
📌 Features
⭐ 1. Pattern Generator

Enter the number of rows and the program generates a right-angled triangle pattern using *.

Example:

*
* *
* * *
* * * *
* * * * *

🔢 2. Number Analyser

Enter a starting number and an ending number to:

Check whether each number is odd or even
Display the result for every number
Calculate the sum of all numbers in the range

Example:

number 1 is odd
number 2 is even
number 3 is odd
number 4 is even
number 5 is odd

sum of all numbers from 1 to 5 is: 15

🚪 3. Exit

Select option 3 to safely exit the program.
